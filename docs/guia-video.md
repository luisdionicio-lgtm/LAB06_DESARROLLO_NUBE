# Guía para la demostración de SecureDocs

Duración sugerida: 7 a 10 minutos.

1. Presentar el problema de TechCorp y explicar la diferencia entre RBAC y ABAC.
2. Mostrar la estructura modular: rutas, controladores, repositorios, servicios y políticas.
3. Enseñar el diagrama de arquitectura y el modelo de datos.
4. Mostrar en Docker Desktop los dos contenedores saludables.
5. Abrir PgAdmin y enseñar roles, permisos, asociaciones, usuarios, documentos y auditorías.
6. Autenticar al administrador en Postman y explicar el JWT.
7. Ejecutar un caso permitido y una denegación RBAC.
8. Ejecutar denegaciones ABAC por departamento, nivel, horario y dispositivo.
9. Mostrar los dos casos del invitado.
10. Consultar auditoría y señalar que registra permitidos y denegados con motivo.
11. Ejecutar `npm test` y `npm run verify`.
12. Cerrar con las medidas aplicadas: bcrypt, JWT, variables de entorno, SQL parametrizado, errores controlados y autorización centralizada.

No muestres el archivo `.env` durante el video.
